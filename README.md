# sitev3 — Mael B.

Personal portfolio built with [Next.js](https://nextjs.org).

## Stack

- **Framework:** Next.js (static export)
- **Styling:** Tailwind CSS v4 + shadcn/ui
- **Animation:** Framer Motion
- **Fonts:** Geist, Anta, Doto (via next/font/google)

## Development

```bash
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build
```

Pushing to `main` automatically deploys to GitHub Pages via GitHub Actions.
